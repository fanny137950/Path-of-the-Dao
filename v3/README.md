# 問道九州 V3 — Living World

此目錄是 V3 的獨立實驗區，與既有 V2 路由、正式 Sites 登入及 D1 存檔分離。**不執行 V2 資料庫遷移，不部署正式站。**

## 已決定
- 單一 ChatGPT 式文字輸入與世界回應；不依賴角色立繪。
- 中央 GM 管理 NPC、事件、知情、時間與敘事。
- 世界狀態由可驗證的程式結算並持久化，AI 不能直接修改既有真相。
- 角色洛河從入門開始；沿用既有 NPC 核心人格及世界觀，但不複製舊世界線進度。
- 動態生成 NPC 必須有唯一 ID、來源、人格、身份、目標、初始知情及持久化紀錄。
- 第一個 Provider 為 OpenAI；預留其他 Provider 的適配器。

## 開發里程碑
M0：獨立分支、規格與 Provider 適配器（進行中）。
M1：獨立 V3 對話頁與安全 API；真實 OpenAI 串接。
M2：中央 GM 的結構化輸出與規則驗證。
M3：事件帳本、角色記憶與世界線持久化。
M4：世界時間、NPC 自主生活與離場事件。
M5：開發者後台、動態 NPC、回歸測試。

## 安全界線
正式部署的站點、登入、存檔保持原狀。V3 使用獨立命名空間與新資料表／資料庫；任何資料遷移須另行審查。OpenAI 金鑰只能由伺服器環境取得，不寫入原始碼、前端或世界存檔。API 必須驗證使用者、限制請求頻率與 token，並記錄用量。

## 現況
目前僅有初步 Provider 程式與規格，**尚無可玩 V3 網頁、資料庫或實際 AI 端到端測試**。
