# V3 人物設定與長期記憶（第一階段）

## 角色與安全
- 玩家取得的 V3 世界資訊只包含對話、時間、地點及主角。
- 開發者視圖另外檢查登入者、世界所有權及伺服器端 GAME_DEVELOPER_USER_IDS；只有授權開發者能閱讀私密資料及修改人物。
- 修改經資料驗證、revision 樂觀鎖與修改日誌保存到 D1。私密備註不會直接回傳一般玩家。

## 角色資料
- 五名初始 NPC 各有固定 ID、身分、境界、靈根、所在地、人格、說話風格、目標、日常計畫、健康、情緒、修行進度、玩家關係、個人記憶與知情列表。
- 初始為收徒執事韓守一、沈滄月、晏清辭、江離、顧長青；洛河尚未入門。
- 既有 V3 存檔載入時，只補缺失欄位，保留已存的角色屬性與記憶。舊版 story-v1 存檔完全不修改。

## 記憶規則
1. 每次成功的對話回合，在 D1 worlds.state 中寫入事件、雙方原文以及親歷者列表。
2. 只有在場、合理可見的 NPC 取得親歷記憶；常見內心獨白被視作私密，不自動共享。
3. GM 輸入採用現場 NPC 固定人格、關係與獨立個人記憶，並以關鍵字加近期性提取舊記憶。其他 NPC 不因此得到知情。
4. 模型回覆可附帶情緒、關係值及到達地點的建議，但須滿足 NPC 在場、文本證據及玩家行動約束，由伺服器驗證才正式提交。
5. 不會讓模型隨意升級修為、直接更改存檔或向不在場角色傳播秘密。

## 當前限制
- 這是人物／記憶持久化第一版：沒有完整 NPC 離場自主日程、技能戰鬥、事件知情擴散或動態生成 NPC。
- 內心／旁聽判定採初步啟發式規則，不能取代完整的潛行、視線與聽覺結算。
- 目前原始事件與長期記憶保存於各世界 D1 JSON 中，1000 回合上限與摘要壓縮需要後續改善。
- 不需要新 D1 遷移，沿用現有 worlds 表的 state/revision。
