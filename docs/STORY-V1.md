# 《問道九州》沉浸式對話原型 v1

核心不變：玩家真正生活在一個不以自己為中心、卻會記住自己存在的世界裡。

本次交付是棲風峰的小型實驗場，不宣稱已完成整個 v3.0 世界。新模式位於 `/`，舊操作實驗保留於 `/legacy`，資料不可混用。新模式從入門後的獨立世界線開始，不自動匯入其他聊天世界線的古城、風痕或人際歷史。

## 使用方式

1. 登入既有網站，建立「棲風峰 · 初識」世界線。
2. 打開設定，選擇 OpenAI / Anthropic / Gemini，在頁面輸入 API 金鑰，測試服務並填入支援文字 JSON 輸出的模型 ID。
3. 在右側輸入自然對白或行動。Enter 接話，Shift+Enter 換行。輸入「繼續」保留玩家控制權，不自動替玩家作重大表態。
4. `心想：…` 是未說出口的想法；`系統` / `系統：…` 查詢目前狀態，不推進時間。
5. NPC 名字切换對話對象。移動由「山河」地圖執行；路程消耗正式時間。
6. 「記憶」查詢帳本；對白旁的書本按鈕可將原句保留為重要記憶。
7. 「記憶 → 許下承諾」明確登記可驗證的修行／見面承諾。這是玩家單方面承諾，不強迫 NPC 改變日程。完成獨處修行後須當面回報；不會變成 NPC 全知。
8. 「光陰」等待或修行，可自訂至五年；未完成約定期限會中斷。
9. 每回合自動保存。「世界線」可手動保存、從目前／歷史節點建立獨立分支。舊世界不覆寫。

## 資料和運算實際存在哪裡

| 資料／運算 | 本版位置 | 作用 |
|---|---|---|
| 畫面和輸入 | 瀏覽器 React | 立繪、連續文字、地圖、面板。不是正式存檔來源 |
| 世界運算 | Cloudflare Worker 上的 `lib/story/world.mjs` | 時間、路程、作息、修行、物品、承諾、關係與正式結果 |
| 行動解析與對話生成 | 後端呼叫所選模型 Provider | 每次傳入有界、按人物知情範圍過濾的上下文；模型無法直接寫資料庫 |
| L1 通用規則 | 版本化 `data/story-rules.json` 和引擎驗證 | 核心契約、權限、時間政策 |
| L2 世界 | `data/taixu.json` | 六個已知地點、固定連接、角色基礎身份 |
| L3 NPC 原生人格 | `data/story-npcs.json` | 價值、說話習慣、目標、日程與成長門檻 |
| L4 世界線／L5 主角 | 雲端 D1 的 `worlds.state` | 日期、修為、庫存、財務、傷勢、NPC 狀態和世界計畫 |
| L6 客觀事件 | D1 `event_ledger` | 不可變事件帳本，含時間、來源、知情者、變更和關聯 |
| L7 個體知識 | D1 `actor_knowledge` | 世界線＋人物＋事件，複合外鍵禁止跨世界引用 |
| 全部對話原文 | D1 `story_messages` | 不可變、有序、含當時在場觀眾；不只保留摘要 |
| 生成中回合 | D1 `story_requests` | 請求指紋、處理租約、狀態；不存 API 金鑰 |
| 已提交回合 | D1 `turn_commits` | 回合 ID 唯一、世界版本唯一，重試不重複扣除 |
| GM 真相 | D1 `sealed_truths` | 固定內容與摘要雜湊；禁止 UPDATE/DELETE；不送玩家或一般 NPC |
| 歷史節點 | D1 `saves` | 世界快照及事件／訊息序號截止點，分支只複製當時以前的歷史 |
| 畫像 | 專案 `public/art` | 可重複引用，不在每句對話重新生成 |

本版真正執行的是 Cloudflare Worker + D1（SQLite），**不是已上線的 FastAPI + PostgreSQL/pgvector**。專案中的 Python/Godot 骨架仍屬後續移植基礎。D1 資料獨立於模型上下文及瀏覽器，換模型或重新整理不會刪除世界。仍需後續建立可下載的完整加密備份、復原演練、資料匯出匯入及保留政策。

## 一個回合的生命週期

讀取已登入帳號擁有的世界 → 驗證回合 ID／版本／內容指紋 → 取得短期處理租約 → 必要時請 AI 回傳結構化意圖 → 引擎在世界副本判定、結算時間與 NPC → 查詢該 NPC 的重要事件、近期對話、承諾、關係和未完話題 → 生成 NPC 回應 → 驗證敘事格式、說話角色、記憶引用、逐字摘錄和部分越權語句 → 資料庫單一原子批次提交 → 顯示已保存結果。

提交先由資料庫 trigger 驗證世界版本和租約。再寫入收據、世界、事件、知情資料、完整對話與請求狀態。任一語句失敗，整批回滾。網路中斷可用相同 ID 重試：已成功則回傳當前正式世界，未成功才重新生成。重新生成仍可能產生額外模型費用；本版保證世界效果不重複，不保證外部 Provider 只計費一次。

## 怎麼兼顧基本都記住與成本

- 所有正式對話原文持久保留，不把摘要當唯一真相。
- 每位 NPC 有各自的未回答問題、話題、人格、關係和知情事件。
- 模型可提議記住本回合重要話語，但只能逐字引用真正說過的玩家文字；程式驗證來源後才保存。
- 玩家亦可手動將原句保留為重要記憶，防止模型漏判。
- 正式承諾独立保存為 active / fulfilled / missed，與截止時間、完成條件及是否回報分開。
- 檢索先做世界線與知情權限過濾，取重要事件、近期事件與關鍵字命中，再拼接最近對話；「誰說過」與「事情是否屬實」分開。
- 本版採精確 SQL＋重要性／時間分組＋文字搜尋。**語意向量、複雜事件圖譜、長期摘要和無上限重要記憶的分層檢索尚未完成。**資料可以一直保存，單次模型上下文仍有限；不可承諾 NPC 能對無限历史的任意細節百分之百即時回憶。

## NPC 如何隨時間進步與判斷

NPC 依原生日程修行、授課、處理事務、休息與旅行。路程按固定地圖計算，人在途中無法當面交談。遠方不逐分鐘呼叫 AI；引擎直接跳到作息、抵達、事件和期限的下一個邊界。

修行時數、疲勞、健康、工作經驗和靈石共同決定進階資格。現有四名 NPC 各實作一次境界小階段進階；並非每次快進人人突破。三年測試中江離與顧長青達成門檻，沈滄月與晏清辭仍需積累。玩家年齡、月例、傷勢與根基進度同步結算。

信任、尊重、親近、戒備、利益、恩怨分開保存；目前**長期数值只由承諾履行、逾期和有來源的回報改變**。每次變化有事件原因，每日有總變動上限，防止一連串小承諾瞬間刷滿關係。普通交談可影響當下情緒與人物語氣，但尚未建立普遍的社交事件評估模型。NPC 缺席無從得知的事情不能直接改變其判斷。

已實作兩個獨立世界計畫：藏經樓修繕及江離宗門委託。玩家不介入仍會結算；不在場就不把幕後結果直接顯示給玩家。並不是完整經濟、政治或自主意識；是具有持續狀態與因果約束的角色模擬。

## 新增的容易忽略之處

- 打字、閱讀及關閉頁面不消耗世界時間，避免玩家思考時錯過接話點。
- 思想、台詞、客觀結果有不同資料類型，台詞保留不代表主張被證實。
- 換人交談不覆蓋其他人的未完話題。
- 重新載入／其他分頁造成版本競爭時拒絕舊提交。
- 玩家完成修行不代表師父親眼看到；承諾收件人可能尚未收到回報。
- 大地圖只顯示最後已知人物位置，不提供遠方全知追蹤。
- 分支按事件與對話序號截斷，而非只用時間，避免同一分鐘後來的對白穿越回過去。
- 本版借用共用庭院美術，介面明示；實際所在地由正式資料決定。

## 驗證與限制

自動化：54 項 Node 測試（新模式 21、先前模式 33）＋16 項 SQLite 測試（新模式 8、先前模式 8）。TypeScript 檢查及正式 production build。

測試涵蓋百回合記憶、秘密隔離、三年成長、傷勢／物品持續、人格與世界線隔離、真假分離、行程、承諾、AI 異常、租約逾期、併發原子提交、不可變原文、歷史分支及 Provider 協定。Provider 採 mock transport 驗證請求／失敗處理；伺服器尚無金鑰，**沒有假稱已完成實際模型生成驗收**。也尚未完成瀏覽器端逐按鈕／裝置視覺 QA。

戰鬥、死亡、完整市場、NPC-NPC 關係演化、動態角色／地圖生成、角色說謊推理、婚姻、主角正式突破、全域矛盾語意校驗及跨平台原生端尚未完成。非法或未支援行動明示限制，不產生假成功敘事。模型語意仍可能出錯，結構與來源檢查不能保證消除所有幻覺。

## 原始碼入口

- `components/story-game.tsx` / `app/story.css`：連續對話與面板。
- `app/api/story/route.ts`：帳號授權、檢索、存檔、租約與原子提交。
- `lib/story/world.mjs`：正式世界規則。
- `lib/story/dialogue.mjs`：意圖解析與 NPC 生成協定。
- `lib/story/providers.mjs` / `app/api/ai/route.ts`：可替換模型與實際金鑰驗證。
- `db/schema.ts` / `drizzle/0002_green_psylocke.sql`：資料模型、不可變歷史、提交 guard。

重現驗證：`node --test tests/*.test.mjs`、`python tests/database_test.py`、`python tests/story_database_test.py`、`npx tsc --noEmit`、`npm run build`。

模型協定參考官方文件：https://developers.openai.com/api/docs/guides/structured-outputs 、https://platform.claude.com/docs/en/api/messages/create 、https://ai.google.dev/api/generate-content 。本版呼叫非串流介面，完整驗證成功後一次顯示；不會把尚未驗證的半句話當正式回合。

## 2026-10-09 模型格式相容修正

行動解析忽略文字副本、說明與其他分支的 null 佔位欄位，只將目前行動允許的參數送入引擎。實際數值修改或衝突參數仍拒絕；格式錯誤最多校正一次，額外呼叫限時 15 秒，成功前不提交世界。未實作行動不以格式重試轉成成功。429 可依安全的服務錯誤代碼區分額度、支出上限與暫時限流，不顯示上游原始訊息或金鑰。此修正以 mock 模型回應驗證；未取得玩家金鑰直接測試 gpt-6-luna。
