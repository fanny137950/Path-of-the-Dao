# 場景式對話 V2

## 玩家體驗

一次輸入推進一小段場景，通常 4–8 個短對白或動作。NPC 可互相插話，主角只補寫少量日常反應。沒有已形成個性時最多一句中性反應，有個性或開發者口吻補充時最多兩句。碰到重要選擇或行程節點立即停止，等待玩家接話。這仍是提交一個完整回合，不是每句一次付費呼叫，也沒有偽造即時串流。

自由輸入先解析為允許的行動提案，再由程式結算，再請模型生成場景。`繼續` 直接使用本地意圖。輸出驗證拒絕缺席發言者、未知記憶引用、過長片段和部分重大代理表態。語意檢查不是完整自然語言證明，仍可能漏掉模型矛盾；不能宣稱完全防幻覺。

## 記憶到底存在哪

正式資料存於部署綁定的 D1 資料庫，不在模型記憶。程式、靜態世界資料與美術存於原始碼；瀏覽器只保存 Provider / model 偏好，session API key 僅在記憶體。

| 資料 | 正式位置 | 用途 |
|---|---|---|
| 通用規則、世界、NPC 原生卡 | `data/*.json` | 共享、可版本管理的基礎設定 |
| 世界狀態、人格觀察、近期生成依據 | `worlds.state` | 每世界線獨立 JSON；revision 控制並行 |
| 客觀事件、台詞事件及來源 | `event_ledger` | 不可變帳本，保留原始內容 |
| 哪個角色知道哪件事 | `actor_knowledge` | 世界線、角色、事件聯合限制 |
| 全部正式對話原文 | `story_messages` | 按 audience 查詢；補寫標為 auto-dialogue |
| 回合請求、租約、提交收據 | `story_requests`、`turn_commits` | 超時重試、衝突和重複提交防護 |
| 固定事件真相 | `sealed_truths` | 不可變真相與雜湊，不進玩家回應 |
| 手動歷史節點 | `saves` | 還原時建立分支，保留原線 |

五層/七層是邏輯分類，不是每層都使用獨立服務。長期摘要及向量檢索尚未實作。檢索目前使用精確知情條件、重要類型、近期排序和文字包含查詢；不是把全部歷史每回合塞給模型，重要記憶檢索仍有條數上限。

## 主角個性成長

模型只能提出列舉的傾向，附本回合玩家親自輸入的逐字證據。程式核對來源為 dialogue/action、存在正式事件且原句相符。AI 補寫、內心旁白與重複原句不計入。首次記為「觀察中」，三筆不同原句後「漸漸形成」；這是可調整啟發式，不是人格診斷。

每筆存原句、訊息 ID、事件 ID、時間、當時聽者；開發者可確認或排除，亦可新增／停用演出口吻。修改留事件與 history，不刪過去。已排除的傾向不再自動累積。個性不代表能力、NPC 情報或玩家未表達的價值承諾。

## NPC、地圖與場景

六處背景以 `data/art-v2.json` 映射；`data/scenes.json` 提供各地實際可敘述物件，避免書樓出現庭院茶桌。四位 NPC 維持自己的日程、路程和成長門檻。

尋人輔助讀 `playerView.locator`，顯示實際位置／在途目的地及抵達時間。這是明確授權的玩家便利資訊，不加入場景模型上下文，也不增加任何角色的知情帳本。選地點先預覽，再確認移動；人物可能提前離去。

多人場景採保守的共同知情檢索：當場所有角色和玩家都知道的事件與對話才傳入。代價是群聊可能暫不提只有兩人知道的往事；日後若要精確私人回憶，應採逐說話者的隔離生成，不能把所有人的秘密放在一份群聊 prompt。

## 原子性與接話

世界先複製；合法性判定與生成成功後，狀態、事件、認知、訊息、收據同批提交。生成失敗不改正式世界。重試沿用 requestId / fingerprint；同 ID 不得換內容。讀取歷史會保留 personality 當時快照、重新映射事件 ID，分支不改原線。

每段依字數估算 0.04–0.35 遊戲分鐘，本場最多 2 分鐘；在日程切換、人物抵達、事件時鐘或承諾期限之前停止。是遊戲耗時估算，非精準語音時間。現實打字和關閉網站不推進。

## 開發者檢視

伺服器 allowlist 與世界線擁有者檢查都通過才可查看；直接打 API 同樣受限制。顯示原生人格、動態關係、行程、個體已知事件與最近一次模型上下文。不是模型內部思考，也不包含 API key。正式玩家 UI 不顯示人物內心數值。

## 驗證與未完成

本次新增 12 個 V2 引擎測試；全套 66 個 Node 測試及 16 個 SQLite 測試。模型呼叫採 mock 協定驗證，沒有使用玩家金鑰做實際 gpt-6-luna 品質測試。無可用瀏覽器控制環境，沒有聲稱滑鼠操作、手機排版與最終視覺已經實測。

尚未實作完整 NPC 私人記憶多代理生成、人物自動新增、戰鬥、完整經濟、無限突破、自然語言承諾自動登記。承諾仍由玩家明確操作確認；關係數值仍主要由可驗證承諾事件更新。
