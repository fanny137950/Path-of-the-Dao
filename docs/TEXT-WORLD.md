# 問道九州 · 純文字自主世界

基於 `codex/ensemble-story-deployment` 的同一份帳號、世界線及存檔格式開發。保持 Sites 身份與 DB binding，沒有啟用獨立 Cloudflare 登入，也沒有重建世界或匯入其他世界線設定。

## 如何使用

1. 進入原世界線，在「設定」選擇 OpenAI、Anthropic、Gemini 或 OpenRouter。填入工作階段 API Key（伺服器已配置時可留空）及模型 ID。
2. 「驗證金鑰與讀取模型」只驗證服務；「測試所選模型實際生成」會發出一次真正的 JSON 生成請求。成功後開始自由對話。
3. 「開發者」可讀取自己世界的 NPC 狀態、日程、修行、情緒、私人目標、人物關係、知情事件和自主事件完整檔案。伺服器先檢查世界所有權；修改演出設定仍受原 `GAME_DEVELOPER_USER_IDS` 控制。
4. 正文一次顯示完整回覆，可自由输入或輸入「繼續」。沒有待答問題且一段對話自然結束時，繼續會略過平靜時段。重要問題不替玩家回答。
5. 「山河」以文字列出地點；遠方人物只保留最後相見位置。原本的即時遠方定位已移出玩家介面。

API Key 只留在頁面記憶體並經後端代理，不寫進瀏覽器儲存、世界存檔、事件帳本或生成紀錄。每個回合可能依序呼叫意圖解析、事件規劃及對話模型，按所選服務計費。OpenRouter 保留原本僅免費模型的限制。

## 四個配合的系統

- `core-rules.mjs`：版本化的十四條世界最高規則，用於意圖、事件導演及敘事。
- `world.mjs` / `world-clock.mjs`：行動時間、日程、路程、修煉、傷勢、承諾與離線补算。
- `living-world.mjs`：AI 預建事件檔、固定真相、證據與取得來源、NPC 推測、時間線、介入與判定。
- `scene.mjs`：依當前可知資料接續對話。私人事件情報使用單一知情 NPC 的隔離上下文，不將其他人的私密資料交給該人物。

## 封存與因果

AI 導演收到當前 NPC、既定人格、地點及先前事件摘要，不收到本次玩家的猜測或自由輸入。只可從此刻建立一項新事件，不能補造已發生的重大歷史。

事件在探索前建立起因、動機、固定事實、證據、推測、2–4 個行動節點與收束條件。檔案經 schema、人物、地點、時序和情報來源檢查後才封存。後台的封存字串與 DB `sealed_truths` 雜湊必須相符；與正式回合一同原子提交。分支會攜帶當時所有事件封存。

固定真相不固定未來。NPC 需依路程趕到行動地點；到場、境界、健康、疲勞、修行、情報、介入影響及可重現隨機會決定結果。NPC 會自主查證所在地的證據、留下私人記憶，合作可改變 NPC 之間的信任。玩家可查證、協助或阻止已知事件；嘗試、成功／失敗與代價保存，不能重複刷同一項判定。

公告只有在所在地看見才取得；秘密不是全宗門即時廣播。事件不要求玩家接取，時間到即結算，最終必須收束。收束後至少一天平靜期，下一個有 AI 連線的回合才建立新事件。

## 持續時間

現實一分鐘對應世界一分鐘；頁面在閒置時每分鐘請伺服器結算。關閉後不持續呼叫 AI，返回時用同一引擎補算 NPC 日程與既有事件。每次最多補算一天，剩餘時間保留於時鐘 anchor，後續繼續結算，沒有丟棄。

舊存檔首次啟用時以當下建立時鐘，不追溯消耗啟用前經過的現實時間。恢復／分支以現在重設現實時鐘，保留遊戲歷史。回合與時鐘同用 revision 唯一鍵，並發時整筆失敗後重新載入，不提交半個回合。

## 本次驗證與實際限制

- 原有 15 組 JavaScript 測試通過；新增自主世界測試驗證舊存檔、封存不變、無玩家介入收束、私密資訊隔離、可重現判定、導演不讀玩家猜測及離線補算。
- 18 項 SQLite 資料庫測試通過；修改的 JSX／TypeScript 通過語法轉譯檢查。
- 當前環境無可用的瀏覽器 QA 工具。套件安裝在供應鏈 metadata 查核時因離線資料缺失中止；尚未完成正式 bundle 建置、瀏覽器操作驗證或使用真實 API Key 的端到端測試。沒有繞過供應鏈政策。
- 尚未完成完整自由戰鬥、偷竊、經濟、死亡、玩家突破及動態新人物／地圖。這些行為仍會明確回報未支援，不能由文字冒充成功。
- 事件目前一次一項、只用四名核心 NPC 和六處地點，先確保封存、時間與資訊隔離。一般對話語意仍由模型生成；結構和引用驗證無法證明每句文字完全無矛盾。
- NPC 個人關係現階段有信任、尊重、親近、衝突與事件依據；依賴、欣賞等更細分情感尚未全部數值化。

此工作分支供審查與測試，沒有部署至正式站。
