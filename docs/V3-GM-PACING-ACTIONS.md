# GM 節奏與情境行動建議

本次修改以已整合 UI 的 `codex/ensemble-story-deployment`（22e2c85）為基礎。

- 移除關鍵字產生的固定行動與必出的「交給 GM 推進」。GM 在既有 GM_STATE 的 suggestions 提供 0–3 項可編輯建議，不增加另一個 AI 請求。
- 每項包含 label、text、evidence；伺服器驗證型別、長度、重複與本回合可見原文依據。這是基本一致性檢查，不能保證模型提出的每個行動語意都恰當。
- 建議隨 assistant 訊息保存；下一回合未提供、空陣列或無效資料都顯示零選項。不從舊回覆沿用。舊存檔不必遷移，首次新版回覆前不顯示猜測按鈕。
- 點擊只填入草稿，送出後才執行。沒有選項時仍可自由輸入「繼續」或任何行動。
- GM 指令要求承接已完成程序、完成有結果的進展，辨別「就這樣」的上下文，不替玩家補情緒與台詞。移除已測靈根就固定安排登記工作的續演指令。
- 現有任務 progressLog 最近紀錄優先进入上下文，保持原本的排程與資料驗證；不自動改寫既有世界進度。

驗證：140 項 Node 測試通過，含建議儲存／重載／清除、錯誤資料、私密狀態不產生按鈕、長對話保留初評進度；TypeScript 檢查通過。沒有使用真實 API 金鑰測試模型敘事品質。

部署：將本分支 PR 合併到 codex/ensemble-story-deployment，再執行 Deploy V3 to Cloudflare，選該部署分支，confirmation 填 wendao-living-world。無新增資料庫 migration。部署後重新整理頁面，用原存檔測試「就這樣」「繼續」及跳場景，確認程序不重演、選項與最後互動吻合。
