## 基本世界

九州有大周仙朝、太虛宗、天劍山、萬獸谷、北荒妖庭與各地商道。妖族、魔族與人族有利益與衝突，不存在天生全善或全惡的種族。傳訊、遠行、丹藥、術法、靈獸、符籙與法器都有成本、風險和前提。

境界：凡人 → 鍛體 → 聚氣 → 築基 → 金丹 → 元嬰 → 化神 → 洞虛 → 合道 → 渡劫（修行境界各有初期、中期、後期、圓滿）。

靈根屬性、靈根純度、綜合資質、修行境界和戰技水平是不同的項目。資質分未知、普通、良、上、卓越、罕見、天驕，是新設定的概略潛力評估，不保證必然能突破。

## 宗門制度

太虛宗弟子等級：雜役、外門、內門、親傳。入宗流程為登記、測靈根、資質與心性評估、錄取和分配生活安排；是否被特定峰主收為親傳另有決策。

**測出純風靈根不代表沈滄月必定當場收徒。** 任何師承都要經過合理相遇、意願、考量與門規。

太虛鐘：一響新客／新弟子，兩響召集，三響公告，六響警戒，九響戰時。正式切磋、宗門功勳、弟子私鬥、物資消耗與跨峰調度依門規執行，不能因 AI 一句敘事便憑空完成。

## 人物資料與權限

每個 NPC 的正式資料含固定 ID、姓名、所屬、身分、境界、靈根、綜合資質、修煉瓶頸、成長潛力、擅長技藝、人格優點缺點、說話口氣、目標、背景、關係、日程、目前位置、情緒、身體狀況、長期記憶、知情、GM 私密背景和資料來源。

有個別記憶不等於全知：山門執事不知道棲風峰私下談的話；見到洛河也不代表 NPC 已經認識她。以前故事線有過師徒、衝突、欠靈石、古城、比武等經歷，不會變成本次新世界的既定歷史。

GM 每回合按當前場景讀取相關門規和在場 NPC 個性；只有提及遠方人物時才讀其公開資訊。完整秘密和人物全表只呈現在授權的開發者後台。

## 洛河的初始狀態

洛河，女，十五歲，青石鎮木匠之女，父洛成安、母柳氏、弟洛小川十一歲。她過往的角色原型有活潑、好奇、自信、嘴硬與膽大，但實際情緒、思想與重大決策由玩家控制。

新 V3 存檔開始時尚未完成測試，不預設靈根已被公開、已拜棲風峰或有風痕。故事保持 ChatGPT 式自由對話；世界規則、記憶、人物與事件計畫在背後運作。

## 實作限制

目前實際整合的是完整的設定資料庫、角色初始資料、根據話題的世界觀檢索和授權後台顯示。所有 NPC 的全面自主排程、互相交流和可影響宗門局勢的多階段事件引擎仍需後續迭代，不能把這版當成全部實現。
