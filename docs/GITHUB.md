# GitHub 交付

交付包含程式、資料庫結構與 migrations、自動化測試、世界／人格 JSON、角色立繪、六處背景與美術來源說明。

不包含部署秘密、API 金鑰、玩家存檔、D1 資料匯出、node_modules、打包快取或執行環境。GitHub 儲存原始碼，不是正式遊玩資料庫；備份存檔需另做資料庫備份。

指定儲存庫：https://github.com/fanny137950/Path-of-the-Dao 。此為使用者建立的公開儲存庫；只同步程式與美術，不同步玩家資料及服務秘密。

`.openai/hosting.json` 為目前 Sites 部署的非秘密識別與 binding 設定；fork 後需換成自己建立的 Site 設定，不能使用原站的登入或資料庫。
