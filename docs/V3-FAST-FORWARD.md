# 《問道九州》choices-1：快進與選擇

參考《80億分之1》的事件與選擇流程，保留自由輸入和現有 L0–L4 記憶。GM 主持世界；程式保存實際經過的時間與決策點，不增加固定劇情導演或 NPC 社交模擬。

## 遊玩流程

- **接著演**：送出「繼續」，延續正在發生的互動。
- **略過日常**：選擇最多 1 小時、1 天、7 天或 30 天，可填目標，例如「到明日晨課」。一次點擊只提交一個回合，沒有自動連續呼叫 AI。
- 時間是上限，不是必須用完的長度。GM 可以在事件提早發生時停下；平靜的一天也可以用日常摘要度過，不必製造危機。
- 遇到重大抉擇顯示「輪到你決定」。點選主要選項直接採取行動；「改寫」先放入輸入框。玩家始終可以自行輸入、拒絕或提出其他做法。
- 有待決事項時不能再按快進跳過；回應後由 GM 判斷是否仍有待決事項。輸入框已有草稿時，快捷操作停用，避免意外略過草稿。
- 每段快進回覆顯示實際經過多久。存檔及重新整理保留目前決策點，舊世界無需重開。

## GM 資訊與資料契約

沿用現有角色式最近對話、工作記憶、角色記憶、事件線與來源檢索。快進目標作為幕外節奏指令送出；時間上限也供記憶檢索選取期間到期的事件，事件結果仍由 GM 根據因果推演。

`GM_STATE` 新增 `decision: {question, evidence} | null`。問題最多 240 字，證據是本回合正文中 4–160 字原文；選項沿用現有 `suggestions` 契約。快進必須明確提供 decision 或 null，以及有效的 `elapsedMinutes`。普通回合保持舊格式相容。

伺服器拒絕已有待決事項的快進、缺少時間或決策欄位、超過時間上限、沒有時間進展也沒有決策，以及快進中變更師承或所屬的狀態更新。拒絕不保存半個回合。其他重大選擇（如新承諾、戀愛或冒險）的判斷仍依賴 GM；格式驗證不能證明敘事語意完全正確。

每筆快進把目標、上限、實際時間及是否停在決策點寫入訊息與事件紀錄，並沿用原始 GM 回覆及前後狀態稽核。請求 ID 包含操作、時間上限及目標；回覆遺失後的相同請求可重取結果，不會因已出現決策點而阻擋重取。revision 比對及世界持有者權限保持有效。
